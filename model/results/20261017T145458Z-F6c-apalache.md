## Configuration

Spec: `model/tla/APA_F6c.tla`, which extends `model/tla/SequencePaxos.tla`. `APA_F6c.tla` sets the constants of `MC_F6c.cfg` with `OVERRIDE_` definitions. Apalache has no model value, so v1 and v2 are entry records:

```
OVERRIDE_Values == {[type |-> "v1", session |-> 0, request_number |-> 0],
                    [type |-> "v2", session |-> 0, request_number |-> 0]}
```

The next-state relation is the part of Next that the constants of F6c enable, with the state constraint of `MC_F6c.cfg` on the next state:

```
ApaNext ==
  /\ \/ \E p \in Pairs : Receive(p[1], p[2])
     \/ \E i \in Nodes, k \in 1..MaxBallot : HandleLeader(i, k)
     \/ \E i \in Nodes, v \in Values : Propose(i, v)
     \/ \E R \in SUBSET Nodes : Rollback(R)
  /\ Bounds'
```

Each other disjunct of Next needs a crash, a wipe, a loss, a duplicate, a timeout, a client session or a read, and F6c allows none of them. TLC keeps no state that violates the CONSTRAINT and checks no invariant in such a state, so `Bounds'` gives the same states. S2Grows is the action invariant `S2GrowsAction == IsPrefix(decided_history, decided_history')`.

Config file `model/tla/APA_F6c.cfg`:

```
INIT Init
NEXT ApaNext
INVARIANTS AcceptedIdxIsLogLength S1 S2 S2b S3 S5 S2GrowsAction
```
