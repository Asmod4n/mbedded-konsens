promise_again_recovery_l1-violation: the form before NoKeepOnSameBallot. A node promises ballot 1 again, then takes the accept sync of ballot 1 a second time; the old sync has an empty log and shortens the log of the node; the voted entry of ballot 1 is gone; ballot 2 votes another entry at index 1 (MajorityVotedOnce). The code keeps the session of the last accept sync (applied_sync_) in memory only, so after a restart the code has the same path. mut_no_keep_recovery_l1 is the same form as a mutation.

promise_again_recovery_l1-keep: with the provisional rule (an accept sync of the accepted ballot never shortens the log), stopped by the time limit of 45 min, no violation.
