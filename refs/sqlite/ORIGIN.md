# Origin of the SQLite documents

Each file here is a page of the SQLite documentation, unchanged. The
SQLite documentation is in the public domain (copyright.html). The
files come from the Ubuntu package sqlite3-doc, version 3.53.4-2, from
the directory /usr/share/doc/sqlite3/ of that package. The SHA-256 of
the .deb is
bac6aa6d6e90b8fec4887877743a0ee97542a227220340d7d36205c372b042e8.
The signature of the archive index was not checked for this package.

| wal.html | the order of the frames in the WAL; durability with synchronous=NORMAL |
