konsensd: sqlite3_step calls per SQL statement on each node, 4096 writes of 64 B at 64 in flight

What was counted
- konsensd_g16A26S2u (write-path 35a6b5d), three nodes, Unix sockets, sync_by_the_caller = true, podman --cpus=3, user 1001.
- bench/sqlcount.cpp is preloaded into each node. It counts each call of sqlite3_step by the SQL text of its statement and writes the counts when the process ends. A SELECT counts one call per row and one at the end.
- One run. The counts include the start, the probe writes and the clean stop. The rate of this run (3924 writes/s) is not a measurement, because the preload takes a lock in each call.
- The leader was node 3. The file of the leader is the one with the most range reads (pid 41); the order of the pids to the nodes is not checked.
- Binary 2a4fd395a8a556ad.
