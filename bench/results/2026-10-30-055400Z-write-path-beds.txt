What was measured
- konsensd, three nodes on one machine, writes of 64 B through PUT /kv,
  with 1 and 64 writes in flight. Writes per second, median latency, and
  the user and system CPU time of the three nodes per write
  (/proc/<pid>/stat fields 14 and 15, CLK_TCK 100).
- Two beds, run alternately, two rounds:
  - shared: the data directories of the three nodes on one btrfs file
    system (one loop image, compress=zstd:1).
  - own: each node on its own btrfs file system (three loop images on
    the same host disk, compress=zstd:1).
- raw SQLite on the same bed: one process, WAL, synchronous=FULL,
  64 B values, 1 and 64 writes per commit.
- One sample per cell. This file is a check of the bed before a plan,
  not a decision of an arm. No A/A noise floor was measured.
