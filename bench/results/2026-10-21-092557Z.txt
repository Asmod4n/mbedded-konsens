# Bench: CRC32C against a MAC per message

Question of the owner (2026-10-21): how much slower is the check of one
log entry with a MAC instead of, or beside, the CRC32C in hardware.

What: one checksum or MAC over one message of 64 B, 1 KiB or 64 KiB.
A sample computes it over 2^24 / size messages, taken in turn from 16
different buffers, and divides the time by that count. Each process
takes 31 samples after one warm-up sample and prints their median. The
loop computes independent messages, so the processor can overlap one
message with the next: the numbers are throughput, not the latency of
one message.

Arms, each its own binary of one source file (outside the tree, given
below):
- CRC_TABLE: the form of src/crc32c.cpp today, a table of 256 values.
- CRC_HW: _mm_crc32_u64 over 8 bytes, _mm_crc32_u8 over the rest.
- HMAC_SHA256: OpenSSL EVP_MAC "HMAC" with SHA-256, a 32-byte key; the
  context is made once and set up again for each message.
- BLAKE2B_MAC: OpenSSL EVP_MAC "BLAKE2BMAC", the same key, output 64 B.
- CRC_HW_HMAC_SHA256: both over the same message.
- CRC_HW2: CRC_HW compiled a second time, for the A/A pair.
Both CRC arms give e3069283 for "123456789", the check value of
CRC-32C.

Run: 7 rounds; each round runs every arm for each size; the order of
the arms turns around each second round. The table compares the median
of the 7 process medians. Run length: 31 samples; the A/A difference
is at most 0.8 %, which is the noise floor.

Build: g++-16 (Ubuntu 16.2.0-3ubuntu1), -std=c++23 -O2 -DNDEBUG
-msse4.2 -Wall -Wextra -Werror, linked with -lcrypto.
Libraries: openssl OpenSSL 4.0.3 29 Sep 2026 (Library: OpenSSL 4.0.3 29 Sep 2026);libcrypto /usr/lib/x86_64-linux-gnu/libcrypto.so.3;glibc ldd (Ubuntu GLIBC 2.44-1ubuntu2) 2.44;.
Machine: Firecracker VM, uname 6.18.44-fc-v140 nproc 4, Intel(R) Xeon(R)
Processor with sha_ni, avx2, avx512f, vaes; cpu flags sha256 733bd6f8a6de28df.
Container: podman, image localhost/cxx-matrix with the Ubuntu package
libssl-dev added.
User and priority: each process runs as the user bench (uid 1001, not
root), started by setpriv, nice 0. other_processes_of_user is 0 in
every row. Not pinned. Threads: 1. Three cpus stayed free.

// Arm is chosen at build time: ARM_CRC_TABLE, ARM_CRC_HW, ARM_HMAC_SHA256, ARM_BLAKE2B_MAC, ARM_CRC_HW_HMAC_SHA256
#include <algorithm>
#include <array>
#include <chrono>
#include <cstdint>
#include <cstdio>
#include <cstring>
#include <limits>
#include <nmmintrin.h>
#include <openssl/core_names.h>
#include <openssl/evp.h>
#include <openssl/params.h>
#include <span>
#include <string>
#include <vector>

namespace {

constexpr std::uint32_t poly = 0x82F63B78u;
constexpr std::array<std::uint32_t, 256> table = [] {
    std::array<std::uint32_t, 256> r{};
    for (std::uint32_t v = 0; v < 256; ++v) {
        std::uint32_t x = v;
        for (int b = 0; b < 8; ++b) x = (x & 1u) ? (x >> 1) ^ poly : x >> 1;
        r[v] = x;
    }
    return r;
}();

[[maybe_unused]] std::uint32_t crc_table(std::span<const std::byte> d) {
    return std::ranges::fold_left(d, ~0u, [](std::uint32_t r, std::byte o) {
        return table[static_cast<std::uint8_t>(r ^ std::to_integer<std::uint32_t>(o))] ^ (r >> 8);
    }) ^ ~0u;
}

[[maybe_unused]] std::uint32_t crc_hw(std::span<const std::byte> d) {
    std::uint64_t c = ~0u;
    std::size_t i = 0;
    for (; i + 8 <= d.size(); i += 8) {
        std::uint64_t w;
        std::memcpy(&w, d.data() + i, 8);
        c = _mm_crc32_u64(c, w);
    }
    auto c32 = static_cast<std::uint32_t>(c);
    for (; i < d.size(); ++i) c32 = _mm_crc32_u8(c32, std::to_integer<std::uint8_t>(d[i]));
    return c32 ^ ~0u;
}

struct mac {
    EVP_MAC* m;
    EVP_MAC_CTX* ctx;
    std::array<unsigned char, 32> key{};
    mac(const char* name, const char* digest) {
        m = EVP_MAC_fetch(nullptr, name, nullptr);
        ctx = EVP_MAC_CTX_new(m);
        std::vector<OSSL_PARAM> p;
        if (digest) p.push_back(OSSL_PARAM_construct_utf8_string(OSSL_MAC_PARAM_DIGEST, const_cast<char*>(digest), 0));
        p.push_back(OSSL_PARAM_construct_end());
        for (std::size_t i = 0; i < key.size(); ++i) key[i] = static_cast<unsigned char>(i * 7 + 1);
        if (!EVP_MAC_init(ctx, key.data(), key.size(), p.data())) std::abort();
    }
    std::uint32_t operator()(std::span<const std::byte> d) {
        std::array<unsigned char, 64> out{};
        std::size_t n = 0;
        if (!EVP_MAC_init(ctx, nullptr, 0, nullptr)) std::abort();
        EVP_MAC_update(ctx, reinterpret_cast<const unsigned char*>(d.data()), d.size());
        EVP_MAC_final(ctx, out.data(), &n, out.size());
        std::uint32_t r;
        std::memcpy(&r, out.data(), 4);
        return r;
    }
};

}

int main(int argc, char** argv) {
    if (argc > 1 && std::string(argv[1]) == "check") {
        const char* v = "123456789";
        auto d = std::as_bytes(std::span(v, 9));
        std::printf("crc_table=%08x crc_hw=%08x expected=e3069283\n", crc_table(d), crc_hw(d));
        return 0;
    }
    const std::size_t size = std::stoul(argv[1]);
    const int samples = std::stoi(argv[2]);
    const std::size_t per = std::max<std::size_t>(1, (std::size_t{1} << 24) / size);
    std::vector<std::byte> buf(size * 16);
    for (std::size_t i = 0; i < buf.size(); ++i) buf[i] = static_cast<std::byte>(i * 131 + 7);
#if defined(ARM_HMAC_SHA256) || defined(ARM_CRC_HW_HMAC_SHA256)
    mac h("HMAC", "SHA256");
#elif defined(ARM_BLAKE2B_MAC)
    mac h("BLAKE2BMAC", nullptr);
#endif
    auto one = [&](std::span<const std::byte> d) -> std::uint32_t {
#if defined(ARM_CRC_TABLE)
        return crc_table(d);
#elif defined(ARM_CRC_HW)
        return crc_hw(d);
#elif defined(ARM_CRC_HW_HMAC_SHA256)
        return crc_hw(d) ^ h(d);
#else
        return h(d);
#endif
    };
    std::vector<double> ns;
    volatile std::uint32_t sink = 0;
    for (int s = 0; s < samples + 1; ++s) {
        std::uint32_t acc = 0;
        const auto t0 = std::chrono::steady_clock::now();
        for (std::size_t k = 0; k < per; ++k) acc ^= one(std::span(buf).subspan((k % 16) * size, size));
        const auto t1 = std::chrono::steady_clock::now();
        sink = sink ^ acc;
        if (s > 0) ns.push_back(std::chrono::duration<double, std::nano>(t1 - t0).count() / per);
    }
    std::ranges::sort(ns);
    std::printf("size=%zu per=%zu samples=%d ns_median=%.2f min=%.2f max=%.2f\n", size, per, samples, ns[ns.size() / 2], ns.front(), ns.back());
}
