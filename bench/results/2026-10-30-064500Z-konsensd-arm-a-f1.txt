What was measured
- konsensd writes of 64 B through PUT /kv, three nodes, one btrfs file system per node (loop images, compress=zstd:1), 1 and 64 in flight.
- Arms, each its own binary, g++ 16.2.0 Release (build-konsensd.sh):
  konsensd_g16: commit edfb54f (sha256 02dc8a4ea7798eef); konsensd_g16cp: the same binary copied (A/A).
  konsensd_g16A: commit 7234281, arms A and F1 (sha256 d5ae0f2b9a9fa365).
- 3 rounds; in each round the arms alternate; each cell is the median of 3 samples (300 writes at 1 in flight, 8192 at 64). Raw SQLite on the file system of node 1 in each round.
- podman --cpus=3, user 1001, not pinned, kernel 6.18.44-fc-v185, Intel Xeon (Firecracker VM), libsqlite3-0 3.53.4-2. Scripts arms.sh and cluster.sh outside the tree: 7d685173ed1f99df 4e9914bf7a83f2b0.
- CPU per write: user and system time of the three nodes (/proc/<pid>/stat) over the three samples.
