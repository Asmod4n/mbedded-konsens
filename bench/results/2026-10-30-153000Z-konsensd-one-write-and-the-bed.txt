konsensd: the path of one write at 1 in flight, and raw SQLite alone against three at once on the same bed

What was measured
- Part 1: konsensd writes of 64 B through PUT /kv at 1 in flight, three nodes, Unix sockets, sync_by_the_caller = true, 300 writes after 300 writes of warm-up.
- Build: commit e17f3e3 (the konsensd code of 1011ddc) plus a diagnostic patch outside the tree (sha256 a4321f642a57c46d). It prints one line with the wall time in us for each client request, each step, each sent message with its kind, each reply, and each submit and completion of an fdatasync.
- The three nodes run on one machine, so their wall clocks are one clock.
- Part 2: raw SQLite (bench/raw_sqlite, WAL, synchronous=FULL, 1 write of 64 B per commit). In each of 4 rounds: one process alone on the file system of node 1, then three processes at the same time, one on the file system of each node.
- g++ 16.2.0 Release, podman --cpus=3, user 1001, not pinned, seccomp profile with io_uring, kernel 6.18.44-fc-v185, three btrfs loop images compress=zstd:1 on one host disk, libsqlite3 3.53.4.

Result, part 1 (medians of the last 300 writes)
- Client request to reply on the leader: 2060 us. The driver measured 430 writes/s.
- fdatasync from submit to completion: node 1 1664 us, node 2 1616 us, node 3 (leader) 1666 us. Each node makes about one fdatasync per write.
- The rest of the path is about 250 us before the syncs start: the leader sends work (kind 16), the followers answer (kind 13), the leader sends AcceptDecide (kind 4). After the first sync of a follower the Accepted (kind 5) reaches the leader, and the leader sends Decide (kind 6) and the reply in 50 us.
- Thus about 80 % of the time of one write at 1 in flight is the fdatasync.

Result, part 2 (writes/s)
round=1 alone 1118 three_at_once 730 694 695
round=2 alone 1196 three_at_once 727 730 734
round=3 alone 1280 three_at_once 723 724 722
round=4 alone 1085 three_at_once 719 722 716
- Median alone: 1157 writes/s (864 us per commit). Median of the three at once: 722.5 writes/s (1384 us per commit).
- Three syncs at the same time on the one host disk make each commit about 1.6 times as long.
- konsensd syncs on all three nodes at the same time for each write. On this bed the reference "raw SQLite alone" thus holds a cost that a cluster with a disk for each node does not have.
