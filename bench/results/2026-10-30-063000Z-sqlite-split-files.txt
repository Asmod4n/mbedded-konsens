What was measured
- Raw SQLite 3.53.4 (libsqlite3-0 3.53.4-2), WAL, one process, 64 B values. Each write: one log row, plus one data upsert; each commit: one meta upsert.
- Arms, each its own binary of one source outside the tree (split.cpp sha256 4d6d54800ffb3572), g++ 16.2.0 -O2:
  split_1: one file, synchronous=FULL, one transaction (as konsensd today). split_1aa: the same binary copied (A/A).
  split_2: log+meta file FULL, data file NORMAL, one thread, log commit then data commit.
  split_3: as split_2, the data commit in a second thread in parallel.
  split_4: log file FULL, meta file FULL, data file NORMAL, three threads in parallel.
- Bed: one btrfs file system (compress=zstd:1, loop image), podman --cpus=3, user 1001, not pinned, kernel 6.18.44-fc-v185, Intel Xeon (Firecracker VM).
- 5 rounds, arms alternate in each round. Batch 1: 1500 writes; batch 64: 64000 writes. Medians, min, max in writes/s.
