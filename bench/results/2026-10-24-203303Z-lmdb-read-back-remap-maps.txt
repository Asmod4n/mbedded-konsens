# What: two forms of the read-back from the disk with the page checksums
# of LMDB 1.0 and MDB_REMAP_CHUNKS. Each message of a step reads
# promise, accepted round, decided index, the last log key and the
# count of entries, appends one entry with MDB_APPEND and writes the
# decided index. A step is the given number of messages in one write
# transaction and ends in a durable commit. Each sample is 10 steps;
# the line gives the median of 31 samples in ns per message.
# Arms:
#    1: the step, no checksum, one map of the file, no read-back.
#   16: the step with mdb_env_set_checksum (CRC32C through the SSE 4.2
#       instruction, 4 bytes per page) and MDB_REMAP_CHUNKS, then a read
#       transaction reads each entry of the step and the decided value
#       again (from the cache).
#   17: as 16, but the read transaction drops the pages of the values
#       (MADV_PAGEOUT on the value range in the chunk mapping), then
#       POSIX_FADV_DONTNEED on the whole file; mincore checks; a second
#       read transaction gets the values again.
#   18: as 17, but POSIX_FADV_DONTNEED only on the file range of each
#       value. The file offset comes from /proc/self/maps, read once for
#       each read-back: the mapping of the LMDB file (device and inode
#       from fstat) that holds the address, its offset plus the distance
#       of the address from the start of the mapping.
# resident_after_pageout counts the pages of the values that mincore
# still finds in memory after the drop. unmapped_values counts values
# whose address no mapping of the file held.
# Why: plan doc/plan-lmdb-only-source.md 2.4 item 8 names the form of
# arm 18 as open (branch lmdb-only-source); the form of arm 17 drops
# the whole file
# (bench/results/2026-10-24-195244Z-lmdb-read-back-remap.txt).
# How: one source file outside the tree (at the end of this file), one
# binary for each arm and an A/A copy (copy b) built the same way. 7
# rounds; the order of the arms and of the copies turns round each even

# virtio disk of the VM), deleted after the run. The code is not in the
