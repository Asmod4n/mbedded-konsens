# Bench: CRC32C forms, one file outside the tree

What: the CRC32C of one payload, taken in turn from 16 buffers, in ns
per operation. One binary per arm, from one source file outside the
tree, built with the flags below:
- table: src/crc32c.cpp at 466f26e (one table of 256 values).
- hw, hw_aa: _mm_crc32_u64 over 8 bytes, then _mm_crc32_u8, in a
  function with target("sse4.2"); built twice (A/A).
- absl: absl::ExtendCrc32c of libabsl-dev.
- google: crc32c::Extend of Google crc32c (github.com/google/crc32c at
  2bbb3be, static library, CMake Release, HAVE_SSE42 1).
- google_portable: crc32c::ExtendPortable of the same library.
Each process checks the CRC of "123456789" against e3069283, takes one
warm-up sample and 31 samples, and prints their median. 7 rounds; the
order of the arms turns around each second round. Each process runs as
the user bench through setpriv, not pinned. Sizes: 64, 1024, 65536 B.
