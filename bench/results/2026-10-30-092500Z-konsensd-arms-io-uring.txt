What was measured
- The arms of the write path again, with io_uring of the kernel. podman runs with a seccomp profile: the default profile of podman plus io_uring_setup, io_uring_enter and io_uring_register (sha256 ccce5e3325a9449a). Each node held an io_uring descriptor (/proc/<pid>/fd) and no epoll descriptor during the run.
- konsensd writes of 64 B through PUT /kv, three nodes, one btrfs file system per node (loop images, compress=zstd:1), 1 and 64 in flight.
- Arms, each its own binary, g++ 16.2.0 Release (build-konsensd.sh): konsensd_g16 (edfb54f, 02dc8a4ea7798eef) and konsensd_g16cp (the same binary copied, A/A); konsensd_g16A (7234281, d5ae0f2b9a9fa365); konsensd_g16F2 (dd179cb, 486d1b0efe993860); konsensd_g16D1 (6207a7d, 51f8368f11e53270).
- 3 rounds; in each round the arms alternate; each cell is the median of 3 samples (300 writes at 1 in flight, 8192 at 64). Raw SQLite on the file system of node 1 in each round.
- podman --cpus=3, user 1001, not pinned, kernel 6.18.44-fc-v185, Intel Xeon (Firecracker VM), libsqlite3-0 3.53.4-2. Scripts arms.sh and cluster.sh outside the tree: 7d685173ed1f99df d9bad1b2fb550242.
